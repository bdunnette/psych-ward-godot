# Psychiatric Ward Tycoon (Godot Version)

This is a Godot 4.2+ project implementing the core mechanics of the "Mind Horizon" psychiatric ward management game.

## Features
- **Isometric Grid**: Custom isometric coordinate system and grid visualization.
- **Game Loop**: Resource calculation (funds, reputation) every 2 seconds.
- **Entity AI**: Patients and staff move autonomously on the grid.
- **Management UI**: Admit patients, hire staff, and monitor facility logs.
- **Stability Logic**: Patient stability fluctuates based on staff efficiency and random factors.

## Project Structure
- `scenes/`: Scene files (.tscn)
- `scripts/`: GDScript logic (.gd)
- `project.godot`: Project configuration and singletons.

## How to Play
1. Download [Godot Engine](https://godotengine.org/).
2. Import this folder into the Project Manager.
3. Run the project (F5).
4. Use the "Admit Patient" and "Hire Staff" buttons to grow your facility.
